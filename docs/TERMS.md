# Terms

- MIB2 High is the vehicle infotainment unit supported by this project.
- QNX 6.5 is the operating system on the unit. ARMv7 is its processor type.
- GAL is the unit process that receives Android Auto from a phone.
- DIO, named `dio_manager` on the unit, receives CarPlay from a phone.
- MMX is the unit computer that runs these phone receiver processes.
- HMI is the unit software that draws screens and handles user input.
- A loader is a library loaded into a receiver to add selected functions.
- `LD_PRELOAD` tells the operating system which libraries to load first.
- A decoder converts compressed video into frames for display.
- FFmpeg supplies the video decoding code used by the decoder.
- SHA256 is a file checksum used to detect different file contents.
- A submodule is a separate Git repository pinned to one selected commit.
- A container runs build tools in an isolated environment on the computer.


- EXLAP is the head unit protocol for named vehicle measurements.
- MOST is the media network used for direct instrument-cluster video.
- A Pi is an ARM QNX test computer. It does not have the instrument cluster.
